# 第8步实验与可视化素材审计报告

## 1. 执行结论

第8步已完成。实验全程离线运行，直接调用项目现有的 A*、ACO、PSO、SA 和“混合优化算法”实现，未调用外部大模型接口，也未使用旧数据库中的手工先验或占位结果。共形成 900 条静态实验记录、500 条动态实验记录和 22 幅计划插图。

本步骤的所有结果仅用于可复现实验和后续技术报告写作，不将受控地图上的结果外推为一般场景结论。

## 2. 实验设计

### 2.1 静态基准实验

- 障碍率：0.15、0.35、0.55。
- 地图规模：30×30、50×50。
- 每个“障碍率×地图规模”组合生成 10 张地图。
- 每张地图运行 5 种算法，每种算法重复 3 次。
- 总执行次数：3×2×10×5×3=900。

### 2.2 动态扰动实验

- 基础障碍率：0.35、0.55。
- 地图规模：30×30。
- 动态变化率：0.03、0.08。
- 每个组合生成 5 张地图，每张地图连续扰动 5 帧。
- 每帧运行 5 种算法，每种算法运行 1 次。
- 总执行次数：2×2×5×5×5=500。

### 2.3 算法运行配置

- A*：沿用项目默认配置。
- ACO：10 只蚂蚁、20 次迭代。
- PSO：10 个粒子、20 次迭代。
- SA：初温 100、降温系数 0.9、最低温度 0.01、每温度最多 10 次迭代。
- 混合优化算法：沿用项目默认实现，即 A* 搜索后进行视线可达平滑；其含义不是车辆运动学语境中的 Hybrid A*。

## 3. 路径合法性复核

实验脚本在算法原始返回值之外增加独立复核：起终点一致性、栅格算法相邻步约束、Hybrid 平滑线段的 Bresenham 碰撞检查、几何路径长度、安全度和转折点计算。地图生成时保留一条单调连通走廊，保证基准地图存在可行解。

审计结果如下：

- 1400 条记录全部可解析。
- “算法报告成功但复核路径非法”的记录为 0 条。
- 所有失败记录均已分类，未分类失败为 0 条。
- 静态地图的实际障碍率与目标障碍率逐条一致。
- 严格 JSON 解析通过，不含 `NaN` 等非标准值。
