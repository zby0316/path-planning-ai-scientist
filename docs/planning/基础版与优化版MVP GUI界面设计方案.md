# 基础版 MVP GUI 界面重新设计

根据比赛 PDF 和你已有的 6 份设计文档，我重新设计了一套**紧扣赛题要求、保留充分优化空间**的 GUI 界面方案。核心设计原则是：

1. **必须输出赛题要求的《科学假设与研究计划》**，不能只展示算法选型；
2. **体现多智能体协作过程**，让评审看到 AI Scientist 的推理链；
3. **保留人在回路接口**，符合赛题“可交互、可教学”要求；
4. **基础版可直接实现，预留扩展插槽**。

***

## 二、页面导航栏（顶部 Tab）

用 Streamlit `st.tabs` 实现多页，基础版 MVP 实现 4 个标签页：

| 标签页          | 基础版内容                              | 优化空间说明                       |
| ------------ | ---------------------------------- | ---------------------------- |
| 🗺 **地图参数**  | 输入障碍率、地图尺寸、连通性、拓扑随机性、算力限制；运行"开始分析" | 后续可增加动态障碍模拟、地图文件上传、3D 地图参数   |
| 📊 **环境分析**  | 显示场景等级判定结果、综合复杂度指数、特征雷达图           | 后续可增加多维特征对比、历史同类场景检索、特征重要性排序 |
| 🤖 **智能体推理** | 展示每个智能体的输入输出卡片，形成完整推理链条            | 后续可增加智能体对话气泡、辩论过程可视化、置信度评分   |
| 📄 **研究报告**  | 展示赛题要求的 10 个标准字段，支持下载 Markdown/PDF | 后续可增加 LaTeX 导出、论文模板选择、参考文献管理 |

```python
# gui/streamlit_app.py — 基础版MVP GUI

import streamlit as st
import sys, os
sys.path.append(os.path.dirname(os.path.dirname(os.path.abspath(__file__))))

from main import PathPlanningDecisionSystem
from map.map_generator import MapGenerator
from map.map_analyzer import MapAnalyzer
from agents.parameter_agent import ParameterAgent
from agents.hypothesis_agent import HypothesisAgent
from gui.visualization import (
    render_map, render_radar_chart, render_bar_chart,
    render_reasoning_chain, render_decision_card,
    render_human_loop_panel, render_research_report
)

# ===== 页面配置 =====
st.set_page_config(page_title="路径规划AI Scientist", layout="wide")
st.title("🔬 路径规划算法自适应选型 AI Scientist 系统")

# ===== 初始化 Session State =====
if "decision" not in st.session_state:
    st.session_state.decision = None
if "env_input" not in st.session_state:
    st.session_state.env_input = {}
if "human_approved" not in st.session_state:
    st.session_state.human_approved = False

# ===== 顶部导航 Tab =====
tab1, tab2, tab3, tab4 = st.tabs(["🗺 地图参数", "📊 环境分析", "🤖 智能体推理", "📄 研究报告"])

# ===== Tab 1: 地图参数输入 =====
with tab1:
    col_left, col_mid, col_right = st.columns([1, 2, 1])

    with col_left:
        st.subheader("📥 地图参数输入")

        obstacle_ratio = st.slider("障碍物占比", 0.0, 1.0, 0.35, 0.01,
                                   help="地图中障碍物所占比例，0~1")
        map_width = st.slider("地图宽度", 10, 500, 100, 10)
        map_height = st.slider("地图高度", 10, 500, 100, 10)
        connectivity = st.slider("通道连通性", 0.0, 1.0, 0.68, 0.01)
        topology_randomness = st.slider("拓扑随机性", 0.0, 1.0, 0.55, 0.01)
        compute_limit = st.radio("算力限制", ["low", "medium", "high"],
                                 index=1, horizontal=True)

        with st.expander("⚙ 高级参数"):
            start_x = st.number_input("起点 X", 0, map_width-1, 0)
            start_y = st.number_input("起点 Y", 0, map_height-1, 0)
            target_x = st.number_input("终点 X", 0, map_width-1, map_width-1)
            target_y = st.number_input("终点 Y", 0, map_height-1, map_height-1)
            dynamic_change_rate = st.slider("动态变化率", 0.0, 1.0, 0.0, 0.01)
            random_seed = st.number_input("随机种子", 0, 9999, 42)

        run_btn = st.button("▶ 开始多智能体分析", type="primary", use_container_width=True)

    with col_mid:
        st.subheader("🗺 地图预览")
        # 生成预览地图
        if run_btn or st.session_state.get("map_grid") is not None:
            gen = MapGenerator(seed=random_seed)
            grid = gen.generate(map_width, map_height, obstacle_ratio,
                                (start_x, start_y), (target_x, target_y))
            st.session_state.map_grid = grid
            fig = render_map(grid, (start_x, start_y), (target_x, target_y))
            st.plotly_chart(fig, use_container_width=True)
        else:
            st.info("点击「开始多智能体分析」生成地图")

    with col_right:
        st.subheader("📋 参数摘要")
        params = {
            "地图尺寸": f"{map_width}×{map_height}",
            "障碍物占比": f"{obstacle_ratio:.0%}",
            "连通性": f"{connectivity:.2f}",
            "拓扑随机性": f"{topology_randomness:.2f}",
            "算力限制": compute_limit.upper(),
        }
        for k, v in params.items():
            st.metric(k, v)

# ===== 执行决策流程 =====
if run_btn:
    env_input = {
        "obstacle_ratio": obstacle_ratio,
        "map_width": map_width,
        "map_height": map_height,
        "connectivity": connectivity,
        "topology_randomness": topology_randomness,
        "compute_limit": compute_limit,
        "start_point": [start_x, start_y],
        "target_point": [target_x, target_y],
        "dynamic_change_rate": dynamic_change_rate,
    }
    st.session_state.env_input = env_input

    with st.spinner("🧠 多智能体系统正在分析..."):
        system = PathPlanningDecisionSystem()
        decision = system.decide(env_input)
        st.session_state.decision = decision

        # 分析地图特征
        analyzer = MapAnalyzer()
        features = analyzer.analyze(grid, (start_x, start_y), (target_x, target_y))
        st.session_state.features = features

        # 获取参数推荐
        param_agent = ParameterAgent()
        params = param_agent.recommend(decision["scene_level"], decision["best_algorithm"])
        st.session_state.params = params

        # 生成科学假设
        hypo_agent = HypothesisAgent()
        hypothesis = hypo_agent.generate(env_input, decision, features)
        st.session_state.hypothesis = hypothesis

    st.success("✅ 分析完成！")
    st.rerun()

# ===== Tab 2: 环境分析 =====
with tab2:

    # ... (显示10个标准字段，下载按钮)
```

## 七、关键设计要点总结

1. **三栏布局**：左栏输入 → 中栏视觉展示 → 右栏决策结果，信息流从左到右自然流动
2. **顶部 Tab 导航**：4 个标签页对应赛题不同关注点，评审可以快速定位想看的内容
3. **底部全宽报告区**：直接展示赛题要求的 10 个标准字段，体现"可验证科学假设输出"
4. **推理链可视化**：让多智能体协作过程透明化，评审能看到每一步的逻辑
5. **人在回路交互**：直接嵌入右侧面板，不打断主流程，符合赛题"可交互、可教学"要求
6. **保留所有扩展点**：每个模块都标注了明确的优化方向，方便方案文档中写"后续工作计划"
7. **Streamlit 快速实现**：基础版全部用 Streamlit 原生组件实现，无需额外前端框架
