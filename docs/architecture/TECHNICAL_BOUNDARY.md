# Technical Boundary

本系统以 Qwen 大模型作为多智能体架构的核心基础模型。

## 技术边界声明

1. **Qwen 为核心基础模型**：本系统的所有智能体推理、决策与生成任务均基于 Qwen 大模型实现，Qwen 是本系统对外统一的核心基础模型。

2. **DeepSeek 仅开发初期临时使用**：DeepSeek 仅在系统开发初期、尚未获取 Qwen API 访问权限时，被临时用于功能测试与流程验证，并非本系统的正式基础模型。

3. **算法选择由数据决定**：最终算法选择由可复现的实验数据和评分函数决定，Qwen 智能体不直接选择算法，仅提供解释与建议。

4. **算法白名单**：本系统允许的算法集合严格限制为 A\*、ACO、PSO、SA、混合优化算法，任何超出该集合的算法均不纳入选型与实验范围。

5. **Qwen 智能体职责清单**：Qwen 智能体负责以下六类工作 —— 解释选型依据、从文献中抽取事实、生成科学假设、生成实验计划、撰写研究报告、充当反思智能体。
