# 路径规划虚拟仿真闭环赛题适配论证方案

## Summary

将项目定位为：**面向救援机器人/无人机路径规划的虚拟仿真实验闭环 AI Scientist 系统**。

系统以动态栅格地图为虚拟实验仪器，研究“不同复杂度、连通性、动态变化和算力约束下，A*、ACO、PSO、SA、混合优化算法的适配边界与性能规律”。

核心结论：现有项目不需要推倒重做，适合从“算法推荐器”升级为赛题方向一 B 的“科学实验任务规划与反馈迭代”作品。

## Key Changes

- 论证文档主线改为：科学问题 -> 虚拟仿真实验仪器 -> AI 任务规划 -> 五算法仿真实验 -> 数据分析 -> 反馈迭代。
- 仿真场景采用双层表达：
  - 内核：动态栅格地图、障碍率、连通性、拓扑随机性、动态变化率。
  - 应用：灾害救援机器人/无人机在未知或变化环境中的路径规划。
- 将现有 `ScientificDiscoveryPipeline`、`ExperimentAgent`、`BenchmarkRunner` 解释为已有闭环基础。
- 明确 Qwen 作用：科学问题理解、文献事实整合、实验计划生成、结果解释、反思和报告生成；算法运行仍由可复现 Python 实验完成。
- 将作品重点从“推荐最优算法”改成“发现路径规划算法适配边界，并根据实验反馈调整下一轮仿真计划”。
