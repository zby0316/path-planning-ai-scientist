# 报告与实验脚本

本目录保存历史技术报告、实验与可视化材料的生成和检查脚本，包括 `run_validated_experiments.py`、报告审计脚本、DOCX/PDF 处理脚本及工作簿检查脚本。

脚本用途和输出位置以各自源码与项目文档为准；部分脚本依赖本地 `assets/`、额外运行环境或外部程序。执行生成类脚本前，请先检查输入和输出路径，避免覆盖已有成果。

现有实验材料见[已验证实验资料](../../evidence/validated_experiments/README.md)；系统当前入口见[主系统说明](../../路径规划虚拟仿真闭环AI科学家系统/README.md)。
